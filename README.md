### Selected Projects

- **[WakeMate](https://github.com/pranavk429/wakemate)** — Native macOS menu bar utility keeping MacBooks awake during long agent runs. Features closed-lid clamshell mode without external displays, display blackout for battery preservation, and an out-of-process root watchdog failsafe. *(Swift, IOKit, POSIX)*
- **[Ark-Agents](https://github.com/pranavk429/Ark-Agents)** — Security gateway and runtime policy filters for autonomous AI agents to prevent secret leakage and unconstrained execution. *(Python, Agent Security)*
- **[echo](https://github.com/pranavk429/echo)** — Autonomous NPC architecture using shared graph memory for persistent cross-session state. *(Graph Theory, Agents)*
- **[Tower-Trace](https://github.com/pranavk429/Tower-Trace) & [Argus](https://github.com/pranavk429/Argus)** — Autonomous agentic tracing and telemetry analysis for diagnosing production systems without manual log searches.
