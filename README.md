### 👋 about me

honestly? i don't really know how to code traditional syntax. 

i just love building things. whenever a random idea pops into my head, i open up an AI tool, vibe code for hours, and see what happens. it's just a fun creative outlet on the side — no fancy corporate agenda, no 10x engineer stuff. 

if it sounds interesting, i'll build it:
- 🎮 weird games & NPC experiments where bots have memory
- 🎧 random audio tools and browser sound playgrounds
- 🛡️ safety guardrails & policy experiments for AI agents
- 🛠️ hackathon projects, debugging toys, and little weekend scripts

---

### 🪵 some things i've messed around with

* **[echo](https://github.com/pranavk429/echo)** — tried building a game where the NPCs actually have a shared hive-mind and remember past interactions using graph memory.
* **[Ark-Agents](https://github.com/pranavk429/Ark-Agents)** — an experiment to see if you can put a safety gateway in front of AI agents so they don't leak private keys or do dumb stuff.
* **[Tower-Trace](https://github.com/pranavk429/Tower-Trace)** & **[Argus](https://github.com/pranavk429/Argus)** — hackathon side projects exploring how AI agents can trace bugs in production without digging through endless logs.
* **[coral-reef](https://github.com/pranavk429/coral-reef)** — a weekend project playing around with multi-agent compliance auditing.
* **audio & web toys** — interactive audio experiments and web tools whenever i want to test sound in the browser.
